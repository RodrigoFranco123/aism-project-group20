Multi-Agent Systems (MAS) and Rational Agents — Lecture Notes

1. Rational Agent Definition: A rational agent is an entity that perceives its environment through sensors and acts upon that environment through actuators to maximize its expected performance measure, given the sequence of percepts it has perceived so far and whatever built-in knowledge it possesses. Rationality is distinct from omniscience, as an agent cannot foresee outcomes that are impossible to infer from available percepts.

2. PEAS Framework: Designing an intelligent agent requires specifying its task environment using the PEAS framework, which stands for Performance measure, Environment, Actuators, and Sensors. For example, in an automated medical diagnosis system, the performance measure includes healthy patient outcomes and reduced costs, the environment consists of the patient and hospital staff, actuators display questions and diagnoses, and sensors receive keyboard entry of symptoms.

3. Task Environment Properties: Environments can be categorized along several dimensions: fully observable versus partially observable, deterministic versus stochastic, episodic versus sequential, static versus dynamic, discrete versus continuous, and single-agent versus multi-agent. A competitive multi-agent environment occurs when one agent's performance measure is inversely proportional to another's, such as in chess, whereas cooperative multi-agent environments reward shared goals.

4. Agent Architectures: Intelligent agents range from simple reflex agents, which select actions based solely on the current percept using condition-action rules, to model-based reflex agents that maintain an internal state to track unobservable aspects of the world. Goal-based agents further incorporate explicit goal information to plan sequences of actions, while utility-based agents map states to real numbers to resolve conflicts between competing objectives under uncertainty.

5. Inter-Agent Communication and Coordination: In multi-agent systems, agents coordinate either through implicit stigmergy (modifying the shared environment) or explicit message passing using standardized Agent Communication Languages (ACLs) like FIPA-ACL. Structured protocols such as the Contract Net Protocol allow a manager agent to decompose tasks, broadcast calls for proposals, evaluate bids from contractor agents, and award sub-tasks without centralized bottlenecks.

**5 Key Concepts:**

1. **Rational Agent Definition**: An entity that perceives its environment and acts to maximize its expected performance measure.
2. **PEAS Framework**: A framework for specifying an intelligent agent's task environment, consisting of Performance measure, Environment, Actuators, and Sensors.
3. **Task Environment Properties**: Environments can be categorized along several dimensions, including observability, determinism, and type (episodic, sequential, etc.).
4. **Agent Architectures**: Intelligent agents can be categorized into simple reflex agents, model-based reflex agents, goal-based agents, and utility-based agents.
5. **Inter-Agent Communication and Coordination**: Agents can coordinate through implicit stigmergy or explicit message passing using standardized Agent Communication Languages (ACLs).

**Multiple-Choice Questions:**

### Question 1: What is the primary goal of a rational agent?

A) To maximize its own performance measure
B) To maximize its own performance measure and minimize the performance measure of other agents
C) To minimize its own performance measure
D) To maximize its own performance measure and minimize the performance measure of other agents, but only in a competitive environment

 Correct answer: D) To maximize its own performance measure and minimize the performance measure of other agents, but only in a competitive environment.

Explanation: Rationality is distinct from omniscience, and an agent's performance measure is not necessarily inversely proportional to other agents' performance measures.

### Question 2: What is the PEAS framework used for?

A) Designing an intelligent agent
B) Specifying an agent's task environment
C) Defining an agent's performance measure
D) Classifying agent architectures

 Correct answer: B) Specifying an agent's task environment

Explanation: The PEAS framework is used to specify an agent's task environment, including its performance measure, environment, actuators, and sensors.

### Question 3: What type of environment is characterized by a deterministic and fully observable environment?

A) Episodic environment
B) Sequential environment
C) Static environment
D) Deterministic and fully observable environment

 Correct answer: D) Deterministic and fully observable environment

Explanation: A deterministic and fully observable environment is characterized by a fixed and complete set of possible states and actions.

### Question 4: What is the primary goal of a goal-based agent?

A) To maximize its own performance measure
B) To minimize its own performance measure
C) To plan sequences of actions to achieve explicit goals
D) To map states to real numbers to resolve conflicts

 Correct answer: C) To plan sequences of actions to achieve explicit goals

Explanation: Goal-based agents incorporate explicit goal information to plan sequences of actions.

### Question 5: What is the primary goal of the Contract Net Protocol?

A) To coordinate agents through implicit stigmergy
B) To coordinate agents through explicit message passing
C) To decompose tasks and broadcast calls for proposals
D) To award sub-tasks to contractor agents

 Correct answer: C) To decompose tasks and broadcast calls for proposals

Explanation: The Contract Net Protocol allows a manager agent to decompose tasks, broadcast calls for proposals, evaluate bids from contractor agents, and award sub-tasks without centralized bottlenecks.
